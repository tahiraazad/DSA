# DSA

A collection of Data Structures and Algorithms implementations in Java, completed as part of my DSA coursework and programming assessments.

This repository contains implementations of fundamental data structures, sorting algorithms, searching techniques, and problem-solving exercises, organised according to six submissions.

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/DSA.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DSA
   ```

3. Navigate to the relevant submission folder.

4. Compile the Java file:

   ```bash
   javac FileName.java
   ```

5. Run the program:

   ```bash
   java ClassName
   ```
